# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that uses the Watson NLP library to analyze text and detect emotions.

The application identifies emotions such as anger, disgust, fear, joy, and sadness from user-provided text.

## Technologies Used

* Python
* Watson NLP
* Flask
* Unit Testing
* Pylint

## Project Tasks

1. Emotion detection using Watson NLP
2. Output formatting
3. Application packaging
4. Unit testing
5. Flask web deployment
6. Error handling
7. Static code analysis
